### 1.1 当前系统优势 ✓

| 模块 | 技术实现 | 优势 |
|------|---------|------|
| **向量检索** | BAAI/bge-small-zh-v1.5 (512维) | 语义理解强，支持中文优化 |
| **混合检索** | Vector + BM25 + RRF 融合 | 多维度召回，精度高 |

| **精排优化** | Cross-encoder reranker | 召回后再精排，提升准确性 |
| **查询扩展** | AI 驱动同义词扩展 | 增强召回率 |
| **批处理** | batch_size=64 (已优化) | 提升 embedding 吞吐量 |

### 1.2 当前短板 ✗

| 维度 | 现状 | AnyTXT 对标 | 差距 |
|------|------|------------|------|
| **文档格式** | 依赖数据库存储的文本 | 100+ 格式解析 | ❌ 无法处理原生文档 |
| **索引更新** | 需手动触发 | 实时增量更新 | ❌ 无自动同步机制 |

| **并发解析** | 单线程 | 多线程文档解析 | ❌ CPU 利用率低 |
| **分布式** | 单机 | HTTP 服务 + 分布式 | ❌ 无扩展能力 |

```python
# 文件: backend/services/retrieval/highlighter.py

class ResultHighlighter:
    """搜索结果片段提取与高亮"""

    def extract_snippet(
        self,
        content: str,
        query: str,
        max_length: int = 200,
        window_size: int = 50
    ) -> str:
        """
        提取包含查询关键词的上下文片段

        Args:
            content: 完整内容
            query: 查询文本
            max_length: 片段最大长度
            window_size: 关键词前后窗口大小

        Returns:
            带高亮的文本片段
        """
        # 1. 查找关键词位置
        positions = self._find_keyword_positions(content, query)

        if not positions:
            # 关键词未找到，返回前N个字符
            return content[:max_length] + "..."

        # 2. 提取上下文窗口
        snippet = self._extract_context_window(content, positions, max_length, window_size)

        # 3. 高亮关键词
        return self._highlight_keywords(snippet, query)

    def _find_keyword_positions(self, content: str, query: str) -> List[int]:
        """查找关键词在文本中的位置"""
        import re
        pattern = re.compile(re.escape(query), re.IGNORECASE)
        return [m.start() for m in pattern.finditer(content)]

    def _extract_context_window(
        self,
        content: str,
        positions: List[int],
        max_length: int,
        window_size: int
    ) -> str:
        """提取上下文窗口"""
        # 计算窗口范围
        windows = []
        for pos in positions:
            start = max(0, pos - window_size)
            end = min(len(content), pos + len(query) + window_size)
            windows.append((start, end))

        # 合并重叠窗口
        merged = self._merge_overlapping_windows(windows)

        # 限制总长度
        result = []
        total_length = 0
        for start, end in merged:
            segment_length = end - start
            if total_length + segment_length > max_length:
                result.append(content[start:start + (max_length - total_length)])
                break
            result.append(content[start:end])
            total_length += segment_length

        return " ... ".join(result)

    def _merge_overlapping_windows(
        self,
        windows: List[Tuple[int, int]]
    ) -> List[Tuple[int, int]]:
        """合并重叠的窗口"""
        if not windows:
            return []

        windows.sort()
        merged = [windows[0]]

        for current in windows[1:]:
            last_start, last_end = merged[-1]
            current_start, current_end = current

            if current_start <= last_end + window_size:
                # 合并
                merged[-1] = (last_start, max(last_end, current_end))
            else:
                merged.append(current)

        return merged

    def _highlight_keywords(self, text: str, query: str) -> str:
        """高亮关键词"""
        import re
        pattern = re.compile(f"({re.escape(query)})", re.IGNORECASE)
        return pattern.sub(r'<mark>\1</mark>', text)
```

# 文件: backend/services/retrieval/regex_searcher.py

class RegexSearcher:
    """正则表达式搜索器"""

    def __init__(self, db_pool: asyncpg.Pool):
        self.db_pool = db_pool

    async def search(
        self,
        pattern: str,
        tables: List[str] = None,
        limit: int = 100
    ) -> List[Dict[str, Any]]:
        """
        正则表达式全文搜索

        Args:
            pattern: 正则表达式模式
            tables: 搜索的表列表
            limit: 返回数量限制

        Returns:
            匹配的文档列表
        """
        tables = tables or ["documents", "guoxue_content", "textbook_blocks_v2"]

        results = []

        for table in tables:
            sql = f"""
                SELECT id, title, content, category,
                       regexp_matches(content, $1, 'gi') as matches,
                       array_length(regexp_matches(content, $1, 'gi'), 1) as match_count
                FROM {table}
                WHERE content ~ $1
                ORDER BY match_count DESC, id
                LIMIT $2
            """
            rows = await self.db_pool.fetch(sql, pattern, limit)

            for r in rows:
                results.append({
                    "id": r["id"],
                    "title": r["title"],
                    "content": r["content"],
                    "category": r.get("category", "未知"),
                    "matches": r["matches"],
                    "match_count": r["match_count"],
                    "source_table": table
                })

        return results[:limit]
```

import asyncio
from typing import Dict, Any, Optional
from tika import parser
from concurrent.futures import ThreadPoolExecutor

class DocumentParser:
    """基于 Apache Tika 的文档解析器"""

    def __init__(self, tika_url: str = "http://localhost:9998"):
        self.tika_url = tika_url
        self.executor = ThreadPoolExecutor(max_workers=4)

    async def parse_file(
        self,
        file_path: str,
        extract_metadata: bool = True
    ) -> Dict[str, Any]:
        """
        解析文档文件

        Args:
            file_path: 文件路径
            extract_metadata: 是否提取元数据

        Returns:
            解析结果: {"content": str, "metadata": Dict}
        """
        loop = asyncio.get_event_loop()

        def _parse():
            return parser.from_file(
                file_path,
                serverEndpoint=self.tika_url,
                meta=extract_metadata
            )

        try:
            result = await loop.run_in_executor(self.executor, _parse)

            return {
                "content": result.get("content", ""),
                "metadata": result.get("metadata", {}),
                "status": "success"
            }
        except Exception as e:
            logger.error(f"解析文档失败 {file_path}: {e}")
            return {
                "content": "",
                "metadata": {},
                "status": "error",
                "error": str(e)
            }

    async def parse_batch(
        self,
        file_paths: List[str]
    ) -> List[Dict[str, Any]]:
        """批量解析文档"""
        tasks = [self.parse_file(fp) for fp in file_paths]
        return await asyncio.gather(*tasks)

    def detect_format(self, file_path: str) -> str:
        """检测文档格式"""
        import os
        ext = os.path.splitext(file_path)[1].lower()

        format_map = {
            '.pdf': 'pdf',
            '.doc': 'msword',
            '.docx': 'msword',
            '.xls': 'msexcel',
            '.xlsx': 'msexcel',
            '.ppt': 'mspowerpoint',
            '.pptx': 'mspowerpoint',
            '.txt': 'text',
            '.epub': 'epub',
            '.mobi': 'mobi',
        }

        return format_map.get(ext, 'unknown')

    def extract_text_only(self, file_path: str) -> str:
        """仅提取文本（轻量级）"""
        result = parser.from_file(
            file_path,
            serverEndpoint=self.tika_url,
            meta=False  # 不提取元数据
        )
        return result.get("content", "")
```

class DocumentIngestionService:
    """文档摄取服务"""

    def __init__(self, db_pool: asyncpg.Pool, parser: DocumentParser):
        self.db_pool = db_pool
        self.parser = parser

    async def ingest_file(
        self,
        file_path: str,
        category: str,
        title: Optional[str] = None
    ) -> int:
        """摄取文件到数据库"""
        # 1. 解析文档
        parsed = await self.parser.parse_file(file_path)

        if parsed["status"] == "error":
            raise ValueError(f"文档解析失败: {parsed['error']}")

        content = parsed["content"]
        metadata = parsed["metadata"]

        # 2. 提取标题
        doc_title = title or metadata.get("title") or os.path.basename(file_path)

        # 3. 生成嵌入向量
        from backend.services.retrieval.vector import VectorRetriever

        vector_retriever = VectorRetriever(self.db_pool)
        embedding = await vector_retriever.embed_text(content)

        # 4. 插入数据库
        sql = """
            INSERT INTO documents (title, content, category, embedding, source_file, metadata)
            VALUES ($1, $2, $3, $4, $5, $6)
            ON CONFLICT (source_file) DO UPDATE
            SET title = EXCLUDED.title,
                content = EXCLUDED.content,
                embedding = EXCLUDED.embedding,
                metadata = EXCLUDED.metadata
            RETURNING id
        """
        doc_id = await self.db_pool.fetchval(
            sql,
            doc_title,
            content,
            category,
            embedding,
            file_path,
            json.dumps(metadata)
        )

        logger.info(f"文档摄取成功: {file_path} -> ID {doc_id}")
        return doc_id
```

# 文件: backend/services/indexing/watchdog_handler.py

import asyncio
from watchdog.observers import Observer
from watchdog.events import FileSystemEventHandler
from typing import Callable, Optional
import logging

logger = logging.getLogger(__name__)

class IndexingEventHandler(FileSystemEventHandler):
    """索引事件处理器"""

    def __init__(
        self,
        callback: Callable[[str, str], None],
        file_extensions: Optional[List[str]] = None
    ):
        """
        初始化事件处理器

        Args:
            callback: 回调函数 (file_path, event_type)
            file_extensions: 监控的文件扩展名
        """
        self.callback = callback
        self.file_extensions = file_extensions or [
            '.pdf', '.docx', '.xlsx', '.pptx',
            '.txt', '.md', '.epub', '.mobi'
        ]

    def on_modified(self, event):
        """文件修改事件"""
        if event.is_directory:
            return

        file_path = event.src_path
        if self._should_process(file_path):
            asyncio.create_task(self.callback(file_path, "modified"))

    def on_created(self, event):
        """文件创建事件"""
        if event.is_directory:
            return

        file_path = event.src_path
        if self._should_process(file_path):
            asyncio.create_task(self.callback(file_path, "created"))

    def on_deleted(self, event):
        """文件删除事件"""
        if event.is_directory:
            return

        file_path = event.src_path
        if self._should_process(file_path):
            asyncio.create_task(self.callback(file_path, "deleted"))

    def _should_process(self, file_path: str) -> bool:
        """判断是否处理该文件"""
        import os
        ext = os.path.splitext(file_path)[1].lower()
        return ext in self.file_extensions


class FileWatcher:
    """文件系统监控器"""

    def __init__(
        self,
        watch_paths: List[str],
        callback: Callable[[str, str], None],
        recursive: bool = True
    ):
        """
        初始化文件监控器

        Args:
            watch_paths: 监控的目录列表
            callback: 文件变化回调
            recursive: 是否递归监控
        """
        self.watch_paths = watch_paths
        self.callback = callback
        self.recursive = recursive
        self.observer: Optional[Observer] = None

    async def start(self):
        """启动文件监控"""
        self.observer = Observer()

        for path in self.watch_paths:
            event_handler = IndexingEventHandler(self.callback)
            self.observer.schedule(event_handler, path, recursive=self.recursive)
            logger.info(f"开始监控目录: {path}")

        self.observer.start()
        logger.info("文件监控服务已启动")

        # 保持运行
        try:
            while self.observer.is_alive():
                await asyncio.sleep(1)
        except KeyboardInterrupt:
            self.stop()

    def stop(self):
        """停止文件监控"""
        if self.observer:
            self.observer.stop()
            self.observer.join()
            logger.info("文件监控服务已停止")

        self.batch_interval = 10  # 秒

    async def handle_file_change(self, file_path: str, event_type: str):
        """处理文件变化事件"""
        logger.info(f"文件变化: {file_path} ({event_type})")

        if event_type == "deleted":
            await self._remove_document(file_path)
        else:
            # 添加到更新队列
            await self.update_queue.put(file_path)

    async def _remove_document(self, file_path: str):
        """从数据库删除文档"""
        sql = """
            DELETE FROM documents WHERE source_file = $1
        """
        await self.db_pool.execute(sql, file_path)

        # 清除相关缓存
        await self.cache_manager.delete(f"doc:{file_path}")
        logger.info(f"文档已删除: {file_path}")

    async def _process_batch(self):
        """批量处理更新队列"""
        while True:
            files = []
            for _ in range(self.batch_size):
                try:
                    file_path = self.update_queue.get_nowait()
                    files.append(file_path)
                except asyncio.QueueEmpty:
                    break

            if not files:
                break

            logger.info(f"批量更新索引: {len(files)} 个文件")

            # 批量摄取文档
            for file_path in files:
                try:
                    await self.ingestion_service.ingest_file(file_path, category="auto")
                except Exception as e:
                    logger.error(f"索引更新失败 {file_path}: {e}")

    async def start(self):
        """启动增量索引服务"""
        logger.info("增量索引服务已启动")

        # 启动批量处理任务
        batch_task = asyncio.create_task(self._batch_processor())

        # 启动文件监控
        watch_paths = [
            "/data/documents",
            "/data/guoxue",
            "/data/textbooks"
        ]

        file_watcher = FileWatcher(
            watch_paths=watch_paths,
            callback=self.handle_file_change
        )

        await file_watcher.start()

    async def _batch_processor(self):
        """批量处理器"""
        while True:
            await asyncio.sleep(self.batch_interval)
            await self._process_batch()
```

# 文件: backend/utils/concurrent.py

import asyncio
from concurrent.futures import ThreadPoolExecutor, ProcessPoolExecutor
from typing import Callable, TypeVar, List
import logging

logger = logging.getLogger(__name__)

T = TypeVar('T')

class ConcurrentExecutor:
    """并发执行器（混合线程池 + 异步IO）"""

    def __init__(
        self,
        max_threads: int = 8,
        max_processes: int = 4
    ):
        """
        初始化并发执行器

        Args:
            max_threads: 最大线程数（CPU 密集型任务）
            max_processes: 最大进程数（阻塞型任务）
        """
        self.thread_pool = ThreadPoolExecutor(max_workers=max_threads)
        self.process_pool = ProcessPoolExecutor(max_workers=max_processes)

    async def execute_threaded(
        self,
        func: Callable[..., T],
        *args,
        **kwargs
    ) -> T:
        """在线程池中执行（CPU 密集型）"""
        loop = asyncio.get_event_loop()
        return await loop.run_in_executor(self.thread_pool, func, *args, **kwargs)

    async def execute_multiprocess(
        self,
        func: Callable[..., T],
        *args,
        **kwargs
    ) -> T:
        """在进程池中执行（阻塞型）"""
        loop = asyncio.get_event_loop()
        return await loop.run_in_executor(self.process_pool, func, *args, **kwargs)

    async def map_threaded(
        self,
        func: Callable[..., T],
        items: List,
        batch_size: int = 10
    ) -> List[T]:
        """并行映射（线程池）"""
        tasks = []
        for i in range(0, len(items), batch_size):
            batch = items[i:i + batch_size]
            task = self.execute_threaded(self._process_batch, func, batch)
            tasks.append(task)

        results = await asyncio.gather(*tasks)
        return [item for batch in results for item in batch]

    @staticmethod
    def _process_batch(func: Callable[..., T], batch: List) -> List[T]:
        """处理批次"""
        return [func(item) for item in batch]

    async def shutdown(self):
        """关闭执行器"""
        self.thread_pool.shutdown(wait=True)
        self.process_pool.shutdown(wait=True)
        logger.info("并发执行器已关闭")


# 应用到文档解析
class DocumentParser:
    def __init__(self, tika_url: str):
        self.tika_url = tika_url
        self.concurrent = ConcurrentExecutor(max_threads=8)

    async def parse_batch(self, file_paths: List[str]) -> List[Dict[str, Any]]:
        """批量解析文档（多线程）"""
        return await self.concurrent.map_threaded(self.parse_file, file_paths, batch_size=10)


# 应用到向量嵌入
class VectorRetriever:
    async def embed_batch_parallel(self, texts: List[str], batch_size: int = 32):
        """并行批量嵌入（多线程 + 批处理）"""
        concurrent = ConcurrentExecutor(max_threads=4)

        def _embed_batch(batch):
            model = _get_model()
            return model.encode(batch, normalize_embeddings=True).tolist()

        # 分批并行处理
        tasks = []
        for i in range(0, len(texts), batch_size):
            batch = texts[i:i + batch_size]
            task = concurrent.execute_threaded(_embed_batch, batch)
            tasks.append(task)

        # 合并结果

from fastapi import FastAPI, HTTPException
from typing import List, Dict, Any
import asyncio
import httpx

class SearchCluster:
    """搜索集群"""

    def __init__(self, nodes: List[str]):
        """
        初始化搜索集群

        Args:
            nodes: 搜索节点列表 ["http://node1:8001", "http://node2:8001"]
        """
        self.nodes = nodes
        self.client = httpx.AsyncClient(timeout=30.0)
        self.current_node = 0

    async def search(
        self,
        query: str,
        category: Optional[str] = None,
        top_k: int = 10
    ) -> List[Dict[str, Any]]:
        """分布式搜索"""
        # 轮询选择节点
        node = self._select_node()

        try:
            response = await self.client.post(
                f"{node}/api/v1/search/hybrid",
                json={
                    "query": query,
                    "category": category,
                    "top_k": top_k
                }
            )
            response.raise_for_status()
            return response.json()["results"]
        except Exception as e:
            logger.error(f"节点 {node} 搜索失败: {e}")
            # 尝试下一个节点
            return await self._search_with_fallback(query, category, top_k)

    async def _search_with_fallback(
        self,
        query: str,
        category: Optional[str],
        top_k: int
    ) -> List[Dict[str, Any]]:
        """故障转移"""
        for node in self.nodes:
            try:
                response = await self.client.post(
                    f"{node}/api/v1/search/hybrid",
                    json={"query": query, "category": category, "top_k": top_k}
                )
                response.raise_for_status()
                return response.json()["results"]
            except Exception as e:
                logger.warning(f"节点 {node} 不可用: {e}")
                continue

        raise HTTPException(status_code=503, detail="所有搜索节点不可用")

    def _select_node(self) -> str:
        """选择节点（轮询）"""
        node = self.nodes[self.current_node]
        self.current_node = (self.current_node + 1) % len(self.nodes)
        return node

    async def health_check(self) -> Dict[str, bool]:
        """健康检查所有节点"""
        results = {}

        for node in self.nodes:
            try:
                response = await self.client.get(f"{node}/health")
                results[node] = response.status_code == 200
            except Exception:
                results[node] = False

        return results

# 文件: backend/services/retrieval/gpu_vector.py

import faiss
import numpy as np
from typing import List, Tuple

class GPUVectorRetriever:
    """GPU 加速向量检索器"""

    def __init__(self, dimension: int = 512, use_gpu: bool = True):
        """
        初始化 GPU 向量检索器

        Args:
            dimension: 向量维度
            use_gpu: 是否使用 GPU
        """
        self.dimension = dimension
        self.use_gpu = use_gpu and faiss.get_num_gpus() > 0

        if self.use_gpu:
            res = faiss.StandardGpuResources()
            self.index = faiss.IndexFlatL2(dimension)
            self.index = faiss.index_cpu_to_gpu(res, 0, self.index)
            logger.info(f"使用 GPU 加速 (GPU 数量: {faiss.get_num_gpus()})")
        else:
            self.index = faiss.IndexFlatL2(dimension)
            logger.info("使用 CPU 检索")

        # 量化索引（提升速度）
        self.quantizer = faiss.IndexFlatL2(dimension)
        self.index_ivf = faiss.IndexIVFFlat(self.quantizer, dimension, 100)
        self.index_ivf.nprobe = 10  # 搜索时探测的聚类数

    def add_vectors(self, vectors: List[List[float]], ids: List[int]):
        """添加向量到索引"""
        vectors_np = np.array(vectors, dtype='float32')

        if self.use_gpu:
            # GPU 索引需要先训练
            if not self.index_ivf.is_trained:
                self.index_ivf.train(vectors_np)
                self.index_ivf = faiss.index_cpu_to_gpu(
                    faiss.StandardGpuResources(),
                    0,
                    self.index_ivf
                )
            self.index_ivf.add_with_ids(vectors_np, np.array(ids))
        else:
            self.index.add_with_ids(vectors_np, np.array(ids))

        logger.info(f"已添加 {len(vectors)} 个向量到索引")

    def search(
        self,
        query_vector: List[float],
        top_k: int = 10
    ) -> List[Tuple[int, float]]:
        """
        搜索最相似的向量

        Args:
            query_vector: 查询向量
            top_k: 返回数量

        Returns:
            [(doc_id, similarity), ...]
        """
        query_np = np.array([query_vector], dtype='float32')

        if self.use_gpu:
            distances, indices = self.index_ivf.search(query_np, top_k)
        else:
            distances, indices = self.index.search(query_np, top_k)

        # 转换为余弦相似度
        results = []
        for idx, dist in zip(indices[0], distances[0]):
            if idx >= 0:  # -1 表示无效
                similarity = 1 - dist  # L2 距离转相似度
                results.append((int(idx), float(similarity)))

        return results

    def save_index(self, path: str):
        """保存索引到磁盘"""
        if self.use_gpu:
            # GPU 索引需要先转回 CPU
            cpu_index = faiss.index_gpu_to_cpu(self.index_ivf)
            faiss.write_index(cpu_index, path)
        else:
            faiss.write_index(self.index, path)
        logger.info(f"索引已保存到 {path}")

    def load_index(self, path: str):
        """从磁盘加载索引"""
        index = faiss.read_index(path)

        if self.use_gpu:
            res = faiss.StandardGpuResources()
            self.index_ivf = faiss.index_cpu_to_gpu(res, 0, index)
        else:
            self.index_ivf = index

        logger.info(f"索引已从 {path} 加载")
```

        self,

                query,
                COUNT(*) as frequency,

                    AVG(similarity) as avg_similarity

                GROUP BY query, session_id

            ORDER BY avg_similarity ASC, frequency DESC
            LIMIT $1

            GROUP BY query

        Args:
            query: 原始查询

        Returns:
            重写后的查询列表
        """
        rewritten = [query]

        # 1. 同义词扩展
        synonyms = await self._get_synonyms(query)
        if synonyms:
            rewritten.extend(synonyms)

        # 2. 拼写纠错（基于历史查询）
        corrections = await self._get_spelling_corrections(query)
        if corrections:
            rewritten.extend(corrections)

        # 3. 相关查询推荐
        related = await self.query_analyzer.get_query_suggestions(query)
        if related:
            rewritten.extend(related[:2])  # 最多2个相关查询

        # 去重
        rewritten = list(set(rewritten))

        return rewritten

    async def _get_synonyms(self, query: str) -> List[str]:
        """获取同义词"""
        # 1. 从领域知识库获取
        sql = """
            SELECT synonym FROM domain_synonyms
            WHERE term = $1
        """
        rows = await self.db_pool.fetch(sql, query)
        synonyms = [r["synonym"] for r in rows]

        # 2. 从 WordNet 获取
        try:
            import nltk
            from nltk.corpus import wordnet

            synsets = wordnet.synsets(query, lang='cmneng')  # 中文 WordNet
            for synset in synsets[:3]:  # 最多3个同义词集
                for lemma in synset.lemmas()[:2]:  # 每集最多2个词
                    if lemma.name() != query:
                        synonyms.append(lemma.name())
        except ImportError:
            pass

        return synonyms

    async def _get_spelling_corrections(self, query: str) -> List[str]:
        """获取拼写纠错建议"""
        # 基于编辑距离匹配历史查询
        sql = """
            SELECT query, COUNT(*) as frequency
            FROM search_logs
            WHERE levenshtein(query, $1) <= 2
            AND created_at > NOW() - INTERVAL '90 days'
            GROUP BY query
            ORDER BY frequency DESC
            LIMIT 3
        """
        rows = await self.db_pool.fetch(sql, query)
        return [r["query"] for r in rows if r["query"] != query]
```

**集成**:
```python
# 文件: backend/services/retrieval/hybrid.py

class HybridRetriever:
    def __init__(self, ...):
        # ...
        from backend.services.search.query_rewriter import QueryRewriter
        self.query_rewriter = QueryRewriter(db_pool)

    async def search(
        self,
        query: str,
        category: Optional[str] = None,
        top_k: int = 10,
        use_query_rewriting: bool = True
    ) -> List[Dict[str, Any]]:
        """混合检索（带查询重写）"""
        # 查询重写
        if use_query_rewriting:
            rewritten_queries = await self.query_rewriter.rewrite_query(query)
            logger.info(f"查询重写: {query} -> {rewritten_queries}")
        else:
            rewritten_queries = [query]

        # 执行多个查询
        all_results = []
        for q in rewritten_queries:
            results = await self._fusion_search(q, category, top_k)
            all_results.extend(results)

        # RRF 合并所有查询结果
        deduped = self._deduplicate_results(all_results)

        # 返回 top_k 结果
        return deduped[:top_k]
```

## 四、技术选型

### 4.1 文档解析

| 技术 | 优势 | 劣势 | 选择 |
|------|------|------|------|
| Apache Tika | 1000+ 格式，成熟稳定 | 依赖 Java，性能一般 | ✅ 推荐 |
| python-docx | 轻量级，Python 原生 | 仅支持 Office | ⚠️ 补充 |
| pdfminer.six | PDF 专用 | 性能差，功能有限 | ❌ 不推荐 |
| pdfplumber | 现代 PDF 解析 | 仅 PDF | ⚠️ 补充 |

**结论**: 主用 **Apache Tika**，补充 **pdfplumber**（PDF 专用）

---

### 4.2 OCR 引擎

| 技术 | 优势 | 劣势 | 选择 |
|------|------|------|------|
| Tesseract | 开源，多语言，Python 支持 | 准确率一般，速度慢 | ✅ 推荐 |
| PaddleOCR | 准确率高，中文优化 | 较新，依赖 PaddlePaddle | ⚠️ 备选 |
| Google Vision API | 准确率最高 | 需付费，依赖云服务 | ❌ 不推荐 |
| EasyOCR | 易用，多语言 | 较新 | ⚠️ 备选 |

**结论**: 主用 **Tesseract**，备选 **PaddleOCR**（如需更高准确率）

---

### 4.3 文件监控

| 技术 | 优势 | 劣势 | 选择 |
|------|------|------|------|
| Watchdog | 跨平台，简单易用 | 性能一般（大量文件） | ✅ 推荐 |
| pyinotify | Linux 原生，高性能 | 仅 Linux，不跨平台 | ⚠️ Linux 环境备选 |
| Polling | 兼容性最好 | 性能差，延迟高 | ❌ 不推荐 |

**结论**: 主用 **Watchdog**，Linux 环境可切换 **pyinotify**

---

### 4.4 全文搜索引擎

| 技术 | 优势 | 劣势 | 选择 |
|------|------|------|------|
| Whoosh | 纯 Python，轻量级 | 性能一般，无分布式 | ⚠️ 小数据集 |
| Elasticsearch | 成熟，功能强大 | 资源消耗大，复杂 | ❌ 过度设计 |
| MeiliSearch | 快速，易用 | 较新，功能有限 | ✅ 推荐（中期） |
| pgvector | 集成 PostgreSQL，简单 | 功能有限 | ✅ 推荐（当前） |

**结论**: 继续使用 **pgvector**，中期评估 **MeiliSearch**

---

### 4.5 向量检索 GPU 加速

| 技术 | 优势 | 劣势 | 选择 |
|------|------|------|------|
| Faiss | 高性能，支持 GPU | 学习曲线陡峭 | ✅ 推荐 |
| hnswlib | 超高性能，轻量级 | 文档较少，Python 绑定有限 | ⚠️ 备选 |
| pgvector GPU 扩展 | 无缝集成 | 需编译，不成熟 | ❌ 不推荐 |

**结论**: 使用 **Faiss**（生产验证）
