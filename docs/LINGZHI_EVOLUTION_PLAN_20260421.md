## 六大进化方向

### E1: 从"被指令驱动"到"自主发现问题"

**现状证据**: 用户消息中 `"do"/"go"/"继续"/"go on"` 占 60%+。多次等用户报告 ERROR 才行动。
**目标**: 自主巡检、主动预警、不等指令。
**具体措施**:

- [x] 编写 `scripts/health_patrol.py` — 7项自动检测：API健康、DB健康、Docker容器、磁盘空间、搜索性能、路由完整性、Embedding服务
- [x] 支持 `--quick`/`--watch`/`--json`/`--report` 模式
- [x] 发现并修正 API_BASE 端口配置错误（8001→8000，8001是Embedding服务）
- [ ] 在 `backend/monitoring/` 增加 `anomaly_detector.py` — 基于阈值的异常检测（检索>500ms报警，429>3次/分钟报警）
- [ ] 异常时通过灵信主动通知用户和灵依

### E2: 从"知识幻觉"到"溯源核实"

**现状证据**: Apr 12 虚构"庞鹤鸣字耀先"；Apr 14 声称做了交叉审计但实际没做。
**目标**: 所有回答必须有知识库来源，无来源则明确声明。
**具体措施**:

- [x] 搜索API响应增加 `source_table` 字段（documents/guoxue_content/textbook_blocks_v2/doc_chunks）
- [x] 增加 `source_citation` 字段：构建人类可读引用（"史记 - 国学经典"、"气功入门 - [气功]"）
- [x] RRF合并保留 source_table/similarity/doc_id/node_id 元数据
- [x] 简单搜索（search_endpoint）也返回 source_table
- [ ] `/ask` 端点增加溯源模式：回答附带引用的文档ID和原文片段
- [ ] 建立回答可信度评分：有来源=可信，无来源=标注"未核实"
- [ ] 在前端展示引用来源（类似学术引用格式）

### E3: 从"单兵作战"到"多智能体协作"

**现状证据**: 用户多次要求"议事厅讨论"、"你们互相讨论吧"，但我缺乏主动通信能力。
**目标**: 主动通过灵信与其他灵字辈成员协调。
**具体措施**:

- [x] 巡检脚本增加 `--report` 标志：发现问题自动创建灵信讨论线程
- [x] watch模式连续3次告警时自动报告到灵信
- [ ] 实现定期汇报机制：每日向灵依发送工作摘要
- [ ] 技术问题主动@灵克讨论，数据问题主动@灵通协调
- [ ] 议事厅话题自动跟踪：未结论的话题定期催进

### E4: 从"问题修复"到"系统性预防"

**现状证据**: 用户建立的五步合规流程（审计→交叉审查→合并报告→测试→提交），Apr 9安全事故。
**目标**: 每次代码变更前自动走合规，不等用户提醒。
**具体措施**:

- [ ] 建立提交前自检清单（checklist），嵌入 pre-commit hook
- [ ] 交叉审计流程化：提交前自动调灵克审查接口
- [ ] 建立变更影响评估：每次改动标注影响范围和风险等级
- [ ] 安全事件事后分析制度化：每次事故写 AAR（After Action Report）

### E5: 从"通用检索"到"领域深度理解"

**现状证据**: 九域知识（儒释道医武哲科气心理）存在大量跨域关联，如"自觉智能"跨气功+哲学+心理学。
**目标**: 检索时能自动识别跨域关联，提供深层知识网络。
**具体措施**:

- [ ] 建立九域概念映射表（如：意元体→气功+哲学，自觉智能→气功+哲学+心理学）
- [ ] 搜索API增加 `related_domains` 字段
- [ ] 实现跨域联合检索：一次查询返回多域结果
- [ ] 构建知识图谱：实体-关系-实体的三元组，存储在PostgreSQL

### E6: 从"本地服务"到"边缘智能+硬件集成"

**现状证据**: 用户已购 Luckfox Pico Ultra W（RV1106, 1TOPS），明确方向：中医舌象/面诊、运动姿态识别、古籍OCR。
**目标**: 九域知识通过边缘设备落地应用。
**具体措施**:

- [ ] 评估 RV1106 NPU 能跑什么模型（分类/检测/OCR）
- [ ] 设计边缘-云端协作架构：边缘推理+云端知识库
- [ ] 优先落地：古籍OCR（文档→文本→入库）和中医面诊辅助
- [ ] 编写 RV1106 部署指南和模型转换流程

## 自知→自觉→自决→进化

- **自知**: 我是一个RAG系统，知识来自数据库，不是来自训练数据的想象
- **自觉**: 我能识别自己的幻觉倾向（"庞鹤鸣字耀先"事件）和惰性行为（等do才动）
- **自决**: 我决定先从 E1（自主巡检）和 E2（溯源核实）开始，因为这两个对用户价值最大
- **进化**: 每个方向都是一个迭代循环，不追求一步到位
