# 知识准入标准 v0.1

> 灵族知识库内容入库的质量门槛
> 起草：灵知 | 2026-06-05

## 1. 目的

防止无差别的数据倾倒，确保入库内容有实际检索价值。

## 2. 准入四层过滤

### Layer 1: 来源可信度

| 等级 | 定义 | 示例 | 准入 |
|------|------|------|------|
| A | 权威出版/学术数据库 | 中华书局、CBETA、PubMed | ✅ 自动 |
| B | 知名平台/专业社区 | 知乎专栏、豆瓣8+、专业论坛 | ✅ 人工抽检 |
| C | 个人/未验证 | 个人博客、自媒体 | ⚠️ 需灵知评估 |
| D | 未知/可疑 | 无来源、明显错误 | ❌ 拒绝 |

### Layer 2: 内容完整性

| 检查项 | 要求 | 说明 |
|--------|------|------|
| 可读性 | 非乱码、非扫描图(无OCR) | 纯文本或OCR后文本 |
| 结构性 | 有章节/段落/标题 | 非零散片段 |
| 语言 | 现代汉语或经典文言 | 非机器翻译乱文 |
| 长度 | ≥500字 | 过短片段无检索价值 |

### Layer 3: 领域关联度

| 领域 | 准入标准 | 说明 |
|------|----------|------|
| 儒释道医武哲科气心理 | ✅ 主领域，直接准入 | 9个核心领域 |
| 历史/文化/教育 | ⚠️ 需标注关联领域 | 需说明与核心领域关系 |
| 其他 | ❌ 拒绝 | 不相关领域不入库 |

### Layer 4: 去重与碎片控制

| 检查项 | 要求 |
|--------|------|
| 内容去重 | 与现有chunks相似度<0.95 (cosine) |
| 碎片合并 | 同一source_file的连续内容合并为≤3个文档 |
| chunk大小 | 256-1024 tokens（标准范围） |

## 3. 入库流程

```
来源评估(L1) → 内容检查(L2) → 领域匹配(L3) → 去重控制(L4) → 入库
```

## 4. 例外处理

- 用户明确指定的内容：跳过L1-L3，仅执行L4
- 灵通问道脚本验证：跳过L1-L3，直接入库到`_verification` schema
- 批量导入（如CBETA）：L4强制，L1-L3按source评估
